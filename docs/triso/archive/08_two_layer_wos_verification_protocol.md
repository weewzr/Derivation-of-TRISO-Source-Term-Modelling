# Two-Layer WOS Verification Protocol

## Goal

Determine whether the implemented Walk-on-Spheres (WOS) interface process reproduces the chosen continuum diffusion model across a material interface.

This protocol is deliberately written so that a high-school student can understand the purpose of each test while every scientific assumption remains explicit.

## 1. Physical setup

Imagine a small spherical fuel region inside a spherical coating.

- Inner radius: a
- Outer radius: R
- Inner diffusivity: D1
- Outer diffusivity: D2
- Interface partition ratio: K

For the first experiment use K=1, meaning the model expects the concentration to be continuous across the interface.

Use a reflecting outer wall for the equilibrium test. This avoids losing walkers through the outer boundary and lets us measure the long-run distribution.

## 2. Exact continuum equilibrium target

With K=1 and no source, the desired equilibrium concentration is uniform.

Uniform concentration means that the fraction of time spent in a region is proportional to its volume.

For an inner sphere of radius a inside an outer sphere of radius R:

$$
f_{in}=\\frac{V_{in}}{V_{total}}=\\frac{a^3}{R^3}.
$$

This target contains no WOS assumptions.

## 3. Interface rule under test

The production implementation uses:

$$
p_{1\\to2}=\\frac{K D_2}{D_1+KD_2}.
$$

For K=1:

$$
p_{1\\to2}=\\frac{D_2}{D_1+D_2}.
$$

The test must never compare the implementation against a reference generated by the same formula. The reference is the continuum equilibrium condition.

## 4. Test matrix

### Diffusivity contrast

Use:

$$
\\frac{D_2}{D_1}=1,\\;10^{-1},\\;10^{-2},\\;10^{-3}.
$$

### Interface resolution

Use several capture distances relative to the inner radius:

$$
\\frac{\\epsilon}{a}=10^{-2},\\;10^{-3},\\;10^{-4}.
$$

### Reinsertion

At each epsilon, test at least:

$$
\\alpha=2,3,5
$$

where the reinsertion distance is

$$
\\delta=\\alpha\\epsilon.
$$

### Statistical sample size

Prefer at least:

$$
N=10^5
$$

histories for final measurements, with a smaller run such as 10^4 for quick debugging.

## 5. Statistical acceptance rule

The measured inner time fraction is:

$$
\\hat f_{in}=\\frac{T_{in}}{T_{in}+T_{out}}.
$$

For independent stochastic sampling, report an empirical standard error or a confidence interval.

Do not claim a deterministic tolerance such as 2% is scientifically sufficient without considering the Monte-Carlo variance and the epsilon/reinsertion errors separately.

A useful first diagnostic is:

$$
e_f=\\hat f_{in}-f_{in}.
$$

Then compare |e_f| with its statistical uncertainty.

## 6. What the equilibrium test demonstrates

A successful result supports:

- the tested interface probability preserves the intended equilibrium density for the tested geometry;
- the tested WOS bulk residence-time mechanism is consistent with that equilibrium observable;
- the implementation's stochastic interface decision is behaving as designed in the tested range.

It does NOT prove:

- transient PDE equivalence;
- correctness of the source-term model;
- the physical validity of the Jiang diffusivity correlation;
- correctness of every TRISO interface;
- correctness of the finite capture distance in general;
- validation against experimental data.

## 7. Epsilon convergence

For a fixed physical problem, define an observable Q(epsilon).

Examples are equilibrium occupancy error or a release-time quantile.

The required behaviour is that Q approaches a stable limit as epsilon decreases.

Do not require a particular convergence order until it is derived for this implementation.

Plot:

$$
|Q(\\epsilon)-Q_{ref}|
$$

against epsilon on a log-log plot when a sufficiently accurate reference is available.

## 8. Reinsertion convergence

At fixed epsilon, vary alpha.

If changing alpha materially changes the final observable, reinsertion is not yet demonstrated to be negligible.

If the result stabilises, record the plateau and retain the smallest-cost parameter that remains within the chosen statistical/ numerical tolerance.

## 9. Partition-ratio test

For non-unit partition ratio, the expected equilibrium concentration relation is:

$$
\\frac{c_2}{c_1}=K.
$$

Repeat the equilibrium experiment for:

$$
K=0.25,0.5,1,2,4.
$$

The measured stationary ratio should be compared with K.

The exact definition of the measured concentration on each side must be documented before the test is run.

## 10. Transient benchmark

After equilibrium tests pass, use the analytical two-layer source problem from `05_two_layer_spherical_benchmark.md`.

Compare WOS against the analytical continuum solution.

At minimum compare:

$$
c(r,t)
$$

and the release or outward-flux observable.

Do not compare only one final number if a spatial or temporal profile can be measured.

## 11. Diagnostic interface alternatives

For research diagnosis only, a second stochastic interface construction can be tested.

One class of discontinuous-diffusion random walks uses a square-root diffusivity skew parameter.

This alternative is not assumed to be correct here.

The scientific question is:

which stochastic process reproduces the continuum problem that the project has explicitly chosen?

## 12. Reproducibility requirements

Every final run should record:

- commit SHA;
- test executable/version;
- geometry;
- D1, D2;
- K;
- capture epsilon;
- reinsertion factor;
- maximum steps;
- random seed;
- number of histories;
- measured observables;
- statistical uncertainty;
- reference value;
- pass/fail decision and its scientific basis.
